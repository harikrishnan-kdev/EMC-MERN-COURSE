## Void elements vs. self-closing syntax

| Comparison | Void elements in HTML | Self-closing syntax |
| --- | --- | --- |
| Meaning | A defined group of elements that cannot contain content and have no end tag | A trailing slash on a start tag; this is syntax, not a separate type of HTML element |
| HTML examples | [`<area>`](CoreBasics/1-Elements.html), [`<base>`](CoreBasics/1-Elements.html), [`<br>`](CoreBasics/1-Elements.html), [`<col>`](CoreBasics/1-Elements.html), [`<embed>`](CoreBasics/1-Elements.html), [`<hr>`](CoreBasics/1-Elements.html), [`<img>`](CoreBasics/1-Elements.html), [`<input>`](CoreBasics/1-Elements.html), [`<link>`](CoreBasics/1-Elements.html), [`<meta>`](CoreBasics/1-Elements.html), [`<source>`](CoreBasics/1-Elements.html), [`<track>`](CoreBasics/1-Elements.html), [`<wbr>`](CoreBasics/1-Elements.html) | Examples: [`<br />`](CoreBasics/1-Elements.html), [`<img />`](CoreBasics/1-Elements.html) |
| How HTML treats it | The element ends at its start tag. Do not write an end tag. | The slash is permitted but unnecessary on void elements. It does not close a non-void HTML element such as `<div />`. |

The list above contains all 13 void elements in HTML. SVG and MathML can also be embedded in HTML documents, but their elements belong to separate vocabularies and are not listed as HTML elements here.

These historical elements are included for recognition, not as recommendations for new pages. Each name links to [1-Elements.html](CoreBasics/1-Elements.html).

| --- | --- |

| [`<big>`](CoreBasics/1-Elements.html) | Enlarged text; use CSS instead |
| [`<center>`](CoreBasics/1-Elements.html) | Centered content; use CSS instead |
| [`<content>`](CoreBasics/1-Elements.html) | Former Web Components insertion point; use `<slot>` |
| [`<dir>`](CoreBasics/1-Elements.html) | Directory list; use `<ul>` |
| [`<font>`](CoreBasics/1-Elements.html) | Styled font size, color, and face; use CSS |
| [`<frame>`](CoreBasics/1-Elements.html) | Defined a frame in a frameset |
| [`<frameset>`](CoreBasics/1-Elements.html) | Contained frame elements |
| [`<image>`](CoreBasics/1-Elements.html) | Precursor to `<img>` |
| [`<marquee>`](CoreBasics/1-Elements.html) | Scrolling text |
| [`<menuitem>`](CoreBasics/1-Elements.html) | Defined a command in a popup menu |
| [`<nobr>`](CoreBasics/1-Elements.html) | Prevented text wrapping; use CSS instead |
| [`<noembed>`](CoreBasics/1-Elements.html) | Fallback content for unsupported embedded content |
| [`<noframes>`](CoreBasics/1-Elements.html) | Fallback content for browsers without frames |
| [`<param>`](CoreBasics/1-Elements.html) | Supplied parameters to an object; obsolete and formerly void |
| [`<plaintext>`](CoreBasics/1-Elements.html) | Treated following content as plain text |
| [`<rb>`](CoreBasics/1-Elements.html) | Marked ruby base text; no longer needed |
| [`<rtc>`](CoreBasics/1-Elements.html) | Grouped ruby semantic annotations |
| [`<shadow>`](CoreBasics/1-Elements.html) | Former Shadow DOM insertion point; use `<slot>` |
| [`<strike>`](CoreBasics/1-Elements.html) | Struck through text; use `<s>` or `<del>` as appropriate |
| [`<tt>`](CoreBasics/1-Elements.html) | Monospaced text; use CSS or a semantic element |
