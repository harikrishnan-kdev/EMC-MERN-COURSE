## 💻 Self-Imposed Constraints

> **Learn by doing.** Use AI as a tutor, not as a substitute for writing code.

| # | Focus | Guideline |
|:---:|---|---|
| 1 | **Try first** | Write your own solution before asking AI for help. |
| 2 | **Ask for guidance** | Request explanations, hints, or debugging help—not complete solutions. |
| 3 | **Own the code** | Understand suggested code fully and rewrite it yourself before using it. |
| 4 | **Debug actively** | Investigate errors yourself first, then ask AI to explain the cause and possible approaches. |
| 5 | **Reflect** | After completing a feature, explain how it works in your own words. |
| 6 | **Review thoughtfully** | Ask AI for code reviews, but decide for yourself which improvements to apply. |
| 7 | **Document with AI** | AI may create or improve Markdown documentation, but must not generate application code. |
